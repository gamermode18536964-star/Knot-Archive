    How your results get in

    1. 1Your browser takes the next open blocks.
      Blocks are handed out in order from the project's global block count, skipping any that are already verified or waiting for a check.
    2. 2You submit them together as one GitHub issue.
      One click opens a filled-in form with the results of every block you ran. Submitting needs a free GitHub account; the issue is your public record.
    3. 3An automated check re-runs each block.
      A GitHub Action repeats the search with the same code. Each block whose fingerprints all match is accepted and adds one to the global block count.
    4. 4New knots are committed with your name.
      knots.json is updated, the site rebuilds, and each new knot's page credits you.
