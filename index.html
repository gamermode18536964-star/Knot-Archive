1 · Search

Volunteers check braid indexes

Index 0, 1, 2… always means the same braid on every computer, so the work splits into blocks of 1,000 that anyone can run from the Contribute page.

2 · Verify

The project re-runs every block

A finished block is submitted as a GitHub issue. An automated check repeats the search and accepts the block only if every result matches.

3 · Publish

knots.json updates, the site rebuilds

Verified knots are committed to the archive with credit to their discoverer. Anyone can download the whole table or help review.
